# Workspace Rules for Scikit-Learn Learning Project

## Challenge File Conventions (`challenge.py`)
- Do NOT include solutions in `challenge.py` files — leave them blank under `TODO` sections for the user to complete.
- Do NOT include generic instructions block text (such as "Instructions:\nComplete the tasks below...\nRun this script...") inside docstrings or header comments.
- Keep the header docstring clean, short, and limited to:
```python
"""
DAY XX ACTIVE RECALL CHALLENGE: <Topic Name>
"""
```
